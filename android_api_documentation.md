# NVIQ API Integration Documentation (Android Frontend)

This document contains all details for the authentication and onboarding API endpoints. 

### **Important Notes for the Frontend Team:**
1. **Long Session Duration**: Authentication tokens (`token`) generated by the backend remain valid for **6 months (180 days)**. Stored tokens do not need to be refreshed frequently.
2. **Authorization Header**: All protected/onboarding endpoints require you to pass the JWT token in the `Authorization` header:
   `Authorization: Bearer <your_jwt_token>`
3. **Flexible Payloads**: The backend is configured to accept common typos and field variations (e.g. `fleetSzie`, `vechileTypes`, `compoany name`) to prevent app crashes.

---

## 1. Authentication Endpoints

### **A. Request OTP**
Dispatches an OTP verification code. If the phone number is not registered, a placeholder user account is created automatically in the database.
* **URL**: `/api/auth/send-otp`
* **Method**: `POST`
* **Content-Type**: `application/json`
* **Request Body**:
```json
{
  "phone": "+919999999999"
}
```
* **Response (Success - `200 OK`)**:
```json
{
  "success": true,
  "message": "OTP sent successfully",
  "isNewUser": true
}
```

---

### **B. Verify OTP (Bypass / Development)**
Allows bypassing OTP verification for testing purposes. If the user doesn't exist, they are auto-created with default role `fleet_manager` and plan `Free Plan`.
* **URL**: `/api/auth/verify-otp-bypass`
* **Method**: `POST`
* **Content-Type**: `application/json`
* **Request Body**:
```json
{
  "phone": "+919999999999",
  "otp": "123456"
}
```
* **Response (Success - `200 OK`)**:
```json
{
  "success": true,
  "message": "OTP verified successfully",
  "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...", // Valid for 180 days (6 months)
  "isNewUser": true,
  "data": {
    "id": "6a11e571668a2c6da36f34df",
    "name": "Fleet-Manager-9999",
    "phone": "919999999999",
    "role": "fleet_manager",
    "status": "active",
    "plan": "Free Plan"
  }
}
```

---

### **C. Validate Stored Session (App Startup)**
Call this endpoint on app startup to verify if the stored local JWT token is still valid.
* **URL**: `/api/auth/validate`
* **Method**: `GET`
* **Headers**: `Authorization: Bearer <your_jwt_token>`
* **Response (Success - `200 OK`)**:
```json
{
  "success": true,
  "valid": true,
  "data": {
    "id": "6a11e571668a2c6da36f34df",
    "name": "Pranjal Sharma",
    "email": "918888888888@nviq.app",
    "phone": "918888888888",
    "role": "fleet_manager",
    "status": "active",
    "plan": "Free plan"
  }
}
```
* **Response (Expired/Invalid - `401 Unauthorized`)**:
```json
{
  "success": false,
  "message": "Token expired — please log in again"
}
```

## 2. Onboarding Endpoints (Protected)

### **A. Onboarding Step 1: Basic Details**
Saves the user's basic profile details. Email is optional.
* **URLs (Use either API route)**:
  * `PUT /api/onboarding/step1`
* **Headers**:
  * `Authorization: Bearer <your_jwt_token>`
  * `Content-Type`: `application/json`
* **Request Body**:
```json
{
  "firstName": "Pranjal",
  "lastName": "Sharma",
  "role": "fleet_manager",            // Must be one of: admin, fleet_manager, dispatcher, operations, owner, driver, supervisor
  "companyName": "NVIQ Tech",       // Also accepts "company", "company name", or "compoany name"
  "plan": "Free plan",               // Optional (defaults to "Free Plan")
  "email": "pranjal@nviq.app"        // Optional (can be omitted)
}
```
* **Response (Success - `200 OK`)**:
```json
{
  "success": true,
  "data": {
    "_id": "6a11e571668a2c6da36f34df",
    "email": "918888888888@nviq.app",
    "role": "fleet_manager",
    "onboardingStep": 1,
    "onboardingComplete": false,
    "plan": "Free plan",
    "company": "NVIQ Tech",
    "firstName": "Pranjal",
    "lastName": "Sharma"
  }
}
```

---

### **B. Onboarding Step 2: Fleet Details (Final Step)**
Saves the fleet information and automatically sets `onboardingComplete` to `true`.
* **URL**: `/api/onboarding/step2`
* **Method**: `PUT`
* **Headers**:
  * `Authorization: Bearer <your_jwt_token>`
  * `Content-Type`: `application/json`
* **Request Body**:
```json
{
  "fleetSzie": "15",                         // Accepts both "fleetSzie" (typo) or "fleetSize"
  "vechileTypes": ["Truck", "Car", "Bike"]  // Accepts both "vechileTypes" (typo) or "vehicleTypes"
}
```
* **Response (Success - `200 OK`)**:
```json
{
  "success": true,
  "data": {
    "_id": "6a11e571668a2c6da36f34df",
    "vehicleTypes": [
      "Truck",
      "Car",
      "Bike"
    ],
    "onboardingStep": 2,
    "onboardingComplete": true,
    "fleetSize": "15"
  }
}
```

---
